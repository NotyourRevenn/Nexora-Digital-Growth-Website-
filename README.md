# ⚡ Nexora — Performance Marketing & Digital Growth Agency

> **Where Brands Meet Growth.** Premium, high-converting digital agency website inspired by the modern aesthetic of Xolio, engineered with fluid micro-interactions, responsive design, and dual-mode theme support.

---

## 🌟 Key Features

- **Dynamic Hero Section**: Interactive constellation particle canvas with mouse repulsion, magnetic cursor glow, and seamless text-cycling headline locked against layout shifts.
- **Continuous 360° Synchronized Orbit Hub**:
  - Rotating celestial orbit featuring 8 growth channels (*Meta Ads, Google Ads, LinkedIn B2B, Shopify Plus, TikTok Viral, WhatsApp API, Viral Studio, SEO*).
  - Self-righting counter-spin on child brand logos to keep them upright and legible throughout the revolution.
  - Hover-to-pause mechanism and live interactive center hub inspector displaying channel metrics and custom brand glow.
- **Interactive ROI & Revenue Simulator**:
  - Dynamic monthly spend slider (₹50k to ₹25L+).
  - Multi-industry selector (*D2C, B2B SaaS, E-Commerce, Local Services*).
  - Real-time client pipeline calculations (Projected Revenue, Net Multiplier, Target CPA) with direct WhatsApp consultation CTA.
- **3D Perspective Tilt Cards**: Realistic specular lighting and gyroscope tilt effect on services and case study cards.
- **Adaptive Dual-Theme (Dark / Light Mode)**:
  - **Dark Theme**: Deep midnight palette (`#080811`), neon cyan (`#00f2fe`), electric violet (`#8340ff`), and hot magenta (`#ff007f`).
  - **Light Theme**: Clean high-contrast palette with vivid brand accents and crisp readability.
- **Fully Responsive**: Optimized for ultra-wide desktops, laptops, tablets, and mobile smartphones.

## 🚀 Quick Start

To run locally:

1. Clone this repository:
   ```bash
   git clone <REPO_URL>
   cd nexora-creative
   ```

2. Open `index.html` directly in your browser:
   - On Windows: Double-click `index.html` or run:
     ```powershell
     Start-Process index.html
     ```
   - Or serve using any local static server:
     ```bash
     npx serve .
     # or
     python -m http.server 3000
     ```
