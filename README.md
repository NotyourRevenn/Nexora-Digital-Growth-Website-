## 🚀 How to Run Locally

Double-click `index.html` in `D:\Websites\nexora-piku\` or start a local server:
```powershell
Set-Location D:\Websites\nexora-piku
python -m http.server 8000
```
Open **`http://localhost:8000`** in your browser.
